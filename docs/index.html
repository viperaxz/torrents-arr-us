torrents-arr-us

One config.json and one command turn a plain Windows box into a complete, hardened, self-hosted media stack — inspired by Swizzin, built for Windows.

Get Started View on GitHub

What it does

A zero-touch installer that boots, installs, wires together and secures 15+ applications. You provide credentials and a domain in one JSON file; everything else is automated.

1. Fill in the config

Domain, admin password, media paths, and which apps you want — all in a single config.json.

2. Run one command

.\master_install.ps1 handles prerequisites, app installers, authentication and integration.

3. It wires itself

Prowlarr indexers sync to Sonarr/Radarr, Deluge becomes the download client, Jellyfin gets libraries, Bazarr gets subtitle profiles — no clicking through UIs.

4. Secured by default

Caddy terminates TLS on every app, CrowdSec + firewall bouncer block attackers, and app ports are LAN-scoped so nothing bypasses the proxy.

The stack

Every app runs as an isolated Windows service under a dedicated seedbox-svc account with no admin rights.

Highlights

Details that took the long way to get right, so you don't have to.

Idempotent installs

Lock files make master_install.ps1 safe to re-run; failed apps are isolated and reported per-app.

Two-phase wiring

Layer 1 sets each app's auth; Layer 2 wires them together via REST APIs. Re-run Layer 2 alone anytime.

Cert cache

Caddy's Let's Encrypt store is AES-encrypted on uninstall and restored on reinstall — no rate-limit surprises.

Service isolation

ACLs are applied per app directory; the secrets folder is readable only by admins and the service account.

Self-unblocking security

Loopback, LAN ranges, Tailscale and your own public IP are whitelisted before CrowdSec can ever ban them.

End-to-end sanity check

sanity_check.py drives the full Prowlarr → Radarr/Sonarr → Deluge → Jellyfin → Bazarr pipeline and reports pass/fail.

Shared users

Users defined once in config.json are created in both Jellyfin and Jellyseerr automatically.

GPU profiles

18 hardware transcoding profiles covering NVIDIA, AMD and Intel generations — or auto-detect with one script.

Getting started

A clean Windows 10/11 machine, a domain, and about 15 minutes. No Docker required.

  1. Clone the repo 
    # PowerShell
git clone https://github.com/viperaxz/torrents-arr-us.git
cd torrents-arr-us
  2. Create your config 
    Copy-Item config.json.example config.json
notepad config.json   # domain, admin password, media paths
  3. Run the installer as Administrator 
    .\master_install.ps1
  4. Open the dashboard Point a browser at your domain — every app is reachable at its own subdomain (Cloudflare mode) or path (DuckDNS mode).
Heads-up: config.json holds your API tokens and passwords and is gitignored by default — never commit it. If you ever remove the install, .\master_uninstall.ps1 preserves your media files, torrent state and Caddy certificates.

Optional add-ons

Flip one flag in config.json to enable them.

Real-Debrid integration

Set "RealDebrid": true plus your API key. Zurg exposes your RD library over WebDAV and rclone mounts it as R:\ — Jellyfin gets a lean "RD Movies" library that streams without touching your disk.

Observability stack

Set "Grafana": true to install Grafana + Loki + Alloy with pre-provisioned dashboards for every seedbox service — or run grafana_enable.ps1 on an existing install.

Hardware transcoding

Run scripts\detect_gpu.ps1 to find your GPU family slug, drop it into Layer2.Jellyfin.GPU, and Jellyfin gets NVENC, AMF or QSV encoding tuned for your exact card.
